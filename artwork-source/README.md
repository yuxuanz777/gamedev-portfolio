# Artwork sources

High-resolution source images used to create optimized website assets:

- `fantasy-hero-original.png` — initial dark-fantasy hero artwork
- `fantasy-hero-runeblade.png` — approved runeblade hero artwork
- `shimmer-cover.png` — Shimmer project cover artwork
